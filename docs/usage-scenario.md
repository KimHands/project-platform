# 실제 사용 시나리오 — 하루 흐름

이 문서는 구현된 기능(A~F)을 실제로 어떻게 쓰는지 하루 흐름으로 보여준다. 모든 명령·동작은 현재 구현 그대로다.

## 0. 최초 1회 세팅 (한 번만)

```bash
cd ~/Desktop/Projects/project-platform
npm install
npm run autostart:install     # 부팅 자동실행 등록 (C) — LaunchAgent, 포트 4319
```

- 이후 맥을 켜서 로그인하면 대시보드가 자동으로 뜬다. 접속: `http://localhost:4319`
- 연구실↔집에서 이어가려면 노트북·집 Windows 양쪽에 Tailscale 설치·같은 계정 로그인(README의 "Orca 원격 이어가기" F2 런북 참고).
- 개발용으로 직접 띄울 때는 `npm run dev` → `http://localhost:3000` (자동실행 4319와 포트가 달라 공존).

## 1. 아침, 연구실 도착 — 오늘 뭐부터 하지?

노트북 로그인 → `localhost:4319` 대기 중. 열어보면:

- Projects · Career 프로젝트가 카드로 한눈에. 각 카드에 상태 배지(기획/진행중/중단/완료) · 진행도 바 · 기술스택 아이콘(Node·Next·React 등) · git 신선도(브랜치·최근 커밋).
- 상단 요약: "규칙 위반 N · 경고 M · 총 K개".
- 위반 배지가 있는 카드 클릭 → 상세 뷰의 규칙 검사에서 무엇을 고쳐야 할지 바로 보인다(폴더명 형식, CLAUDE.md 첫 줄 `@AGENTS.md`, AGENTS.md 존재 등). 마감 있는 건 Projects, 끝없는 진로는 Career라는 워크플로우 법칙을 플랫폼이 대신 감시한다.

## 2. 새 과제 시작 — 폴더를 플랫폼에서 만든다

Finder를 열지 않고 대시보드 우상단 "+ 새 프로젝트" 클릭 → 모달:

- 폴더명 `2026-blockchain-seminar` (입력 중 규칙 실시간 검증 — 대문자·공백·한글 치면 즉시 경고, 생성 버튼 비활성)
- 카테고리 `Projects (마감·산출물)`, 설명, 상태 `기획`, 태그 `seminar, security`
- 생성 위치 미리보기 `~/Desktop/Projects/2026-blockchain-seminar` 확인 후 생성

→ 로컬에 폴더 + `CLAUDE.md`(`@AGENTS.md`) + `AGENTS.md` + `project.json`이 규칙 준수 골격으로 자동 생성되고, 대시보드에 바로 카드로 뜬다(만들자마자 규칙 위반 0). 같은 이름 폴더가 이미 있으면 거부(덮어쓰지 않음).

## 3. 개발 중인 프로젝트 실행해서 확인

프로젝트 상세 뷰 → 실행 섹션에 실행할 명령이 투명하게 표시된다:

> 실행 명령: `npm run dev` · `~/Desktop/Projects/<프로젝트>`

"동작" 클릭 → 프로세스 그룹으로 구동. 실행 중이면:

- "실행 중 (PID …)" 배지
- `http://localhost:<port>` 열기 링크(새 탭)
- 로그 tail 표시(에러가 바로 보인다)

확인이 끝나면 "중지" → npm이 띄운 자식까지 프로세스 트리 통째로 정리.

> 안전: 실행되는 명령은 그 프로젝트 `project.json`의 `run.cmd`에서만 온다. 웹에서 임의 명령을 주입할 수 없다.

## 4. 퇴근 — 연구실 노트북에 세션 켜두고 감

집 Windows에서 이어서 작업하려면:

1. Orca 데스크톱 앱을 닫는다(serve 모드 전환을 위해 — 데스크톱과 `orca serve`는 공존 불가).
2. 대시보드 상단 Orca 패널 → 감지된 Tailscale 주소 확인 → "원격 이어가기 시작".
3. 화면에 뜬 집 Windows용 브라우저 URL(+QR)을 기록하고, 노트북 잠자기 해제 후 퇴근.

## 5. 집 — Windows 컴퓨터(Orca 미설치)에서 이어서

브라우저에 그 URL을 붙여넣기 → 같은 Tailnet이라 연구실 노트북의 Orca 세션에 접속 → 설치 없이 이어서 개발. 모바일이면 QR을 스캔.

> 안전: `orca serve`는 감지된 사설(Tailscale/LAN) 주소에만 바인딩된다. 공개 인터넷 노출(리버스프록시)은 하지 않는다.

## 6. 주말 회고

대시보드를 훑어 진행도·상태 변화를 본다. 각 `project.json`의 `progress`/`status`만 갱신하면 대시보드에 반영된다. 규칙 위반 배지 0 유지 = 워크플로우가 깔끔하다는 뜻.
